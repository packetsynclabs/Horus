# Horus Documentation

This directory contains the canonical documentation for the Horus microkernel.

## Documents

- `ROADMAP.md` — Planned features and development priorities.
- `ARCHITECTURE.md` — High-level design and philosophy.
- `LIMITATIONS.md` — Honest assessment of what does *not* work yet (read this).
- `BUILDING.md` — How to build and run the kernel.

All documentation uses British English.

For contribution guidelines, see the top-level `CONTRIBUTING.md`.
